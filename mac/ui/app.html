Writing

Hinglish spelling

Numbers as digits

“chaar baje” becomes “4 baje”, “do hazaar rupaye” “₹2000”. Words that are also ordinary words (ek, do, saath) change only next to baje, percent, rupaye…

Find who spoke

If something is off

Holding the key does nothing

macOS has not let indite notice key presses. System Settings → Privacy & Security → Accessibility → switch on indite, then quit and reopen it.

The pill says “copied”

There was no text box to type into, so the words went to the clipboard. Paste with ⌘V.

It cannot hear you

Usually a Bluetooth headset that is off. indite tries every microphone, and says so if none work.

The pill says “password box”

indite never types, copies or saves what you say into a password field.

Start indite when you log in

System Settings → General → Login Items → + → choose indite.app.

Set up indite

Four steps, about a minute. Everything stays on this Mac.

  1. 1
    Let indite notice the key and type for you

    System Settings → Privacy & Security → Accessibility → switch on indite. Then quit and reopen indite from the menu bar.

  2. 2
    Let indite hear you

    macOS asks once. If you said no before, turn indite on under Privacy & Security → Microphone.

  3. 3
    Pick the key you hold to talk

    One you do not use for anything else.

  4. 4
    Try it

    Click in the box, hold , say “Hello indite, yeh mera pehla test hai”, and let go.
